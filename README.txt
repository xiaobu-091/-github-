照片管家 · iPhone 本地相簿 PWA

功能
  - 两个页面：相簿页 / 导入页
  - 从手机相册选择照片，按相簿分类导入
  - 创建、删除相簿
  - 相簿内浏览缩略图，点击可删除单张照片
  - 所有数据保存在本机浏览器 IndexedDB，不依赖服务器，不随域名消失

安装到 iPhone（只需一次）
  1. 把本文件夹放到任意静态服务器 / NAS / 或电脑本地起个服务
  2. iPhone 用 Safari 打开访问地址
  3. 点击 Safari 底部「分享」按钮 →「添加到主屏幕」
  4. 桌面出现「照片管家」图标，点开即可全屏使用

使用提示
  - 首次打开后建议点击「添加到主屏幕」，PWA 模式下的数据更稳定
  - 照片导入时会自动压缩（最长边 1920，JPEG 0.85）并生成缩略图
  - 只要不清除浏览器站点数据，相簿和照片就会一直保留
  - 删除相簿会同时删除该相簿内的所有照片数据

限制说明
  - 这是 PWA 网页版，不能自动扫描 iPhone 全部照片，需要你在「导入」页手动选择
  - 不能创建 iOS 系统相簿，只能在应用内建立独立相簿
  - 大容量导入受浏览器存储配额限制，建议导入精选照片而非全部图库
